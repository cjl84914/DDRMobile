# StepMania visual assets

Copied without modification from the local StepMania checkout:

- `judgment.png`: `Themes/default/Graphics/Judgment Normal 2x6.png` (columns are early/late variants; rows W1–W5 and Miss).
- `arrow.png`: `NoteSkins/dance/default/_arrow 1x8 (doubleres).png` (first frame used).
- `receptor.png`: `NoteSkins/dance/default/_receptor (doubleres).png`.
- `glow.png`: `NoteSkins/dance/default/_glow (doubleres).png` (tap explosion glow).
- `life-frame.png`: `Themes/default/Graphics/LifeMeter bar frame.png`. The fill is drawn using simple segmented quads, inspired by `Themes/default/Graphics/ScreenGameplay lifebar_bar.lua`.
- `combo-numbers.png`, `combo-stroke.png`: `Themes/default/Fonts/_roboto Bold 54px [numbers] 4x5 (doubleres).png` and corresponding `[numbers-stroke]` image; digit layout from `_roboto Bold 54px.ini`.

The source project is https://github.com/stepmania/stepmania. These are theme/note-skin artwork, not a claim that the code license automatically covers the graphics. Individual artwork licensing and redistribution permission remain unverified; confirm before distribution.
